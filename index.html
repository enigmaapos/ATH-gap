Calculation: EMA70 and EMA200 are standard recursive EMAs seeded with the SMA of the first period. Bullish cross = previous EMA70 ≤ previous EMA200 and current EMA70 > current EMA200. Bearish cross = previous EMA70 ≥ previous EMA200 and current EMA70 < current EMA200. EMA200 touch = a completed candle whose low ≤ that candle's EMA200 ≤ high. Only the current 08:00–08:00 Asia/Manila session is used for the displayed cross/touch result. The scanner excludes non-trading, non-USDT, and non-PERPETUAL contracts from Binance USDⓈ-M exchangeInfo.

For rate-limit safety this production build uses at most 499 klines per symbol (2 request-weight units under Binance's documented kline tiers), limited concurrency, progressive scheduling, cancellation, and exponential backoff.
