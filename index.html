📦 Box Base Research & Profitability Backtest

Standalone research harness using the Box Base detector from your scanner. This version tests up to 30 Binance Futures USDT perpetuals, multiple signals per coin, TP/SL parameter combinations, state/direction performance, drawdown, MFE/MAE, and trade-level results.

1 · Test Setup

Binance Futures · 15m · public market data
Ready. Historical requests are paginated sequentially with a delay to reduce API pressure. No API key is required.
How the test works

The detector is evaluated only on candles completed at each snapshot. A qualifying signal opens at the snapshot close. TP1, TP2 and SL are then checked candle-by-candle. If TP and SL are both touched in one 15m candle, SL is assumed first because OHLC data cannot prove intrabar order. A trade is TP2 if TP2 is reached before SL, TP1 if TP1 is reached but TP2 is not, FAIL if SL is reached before TP1, and TIMEOUT if neither terminal target nor SL is reached before the horizon. MFE and MAE are measured over the forward window. Trades can be non-overlapping or allow limited concurrency according to the setting.

9 · Research Notes

  • 30 coins × 3,000 candles is roughly 90,000 15m candles, about 31 days per coin.
  • The downloader paginates older Binance candles instead of stopping at the latest 1,500.
  • The Box Base formula itself is preserved from the current standalone detector; this page changes the research harness around it.
  • OHLC data cannot determine exact intrabar order when TP and SL occur in the same candle, so the tester uses the conservative SL-first assumption.
  • Fees are subtracted from each completed trade. Position sizing affects equity-style drawdown calculations but the displayed trade P/L percentages remain price-move percentages net of fees.
  • A large MFE with a FAIL can indicate that the signal moved correctly before reversing; that is useful for testing trailing stops or alternative exits.
