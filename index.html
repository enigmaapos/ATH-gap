Calculation used

Cross: exact EMA70/EMA200 crossing: previous EMA70 ≤ previous EMA200 and current EMA70 > current EMA200 = bullish; previous EMA70 ≥ previous EMA200 and current EMA70 < current EMA200 = bearish. Only crosses whose current candle starts inside the current 08:00–08:00 Philippines session are counted. The newest qualifying cross wins. If none occurs, result is NONE.

EMA200 touch: for every completed candle in the current 08:00–08:00 Philippines session, EMA200 is calculated for that exact candle. A touch is true only when low ≤ candle EMA200 ≤ high. This does not use the latest EMA200 for all candles and does not use a proximity percentage.
